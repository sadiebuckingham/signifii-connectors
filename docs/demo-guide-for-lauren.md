# Little Lantern Media Plans: try the demo in your own Claude

This is a demo built for small kids' and family media agencies. Everything in it is **fictional**: the agency (Little Lantern Media), the client (Bramble Bots), the rate card and the audience files. Please don't add real client files.

It takes about 3 minutes to add and works on claude.ai and the Claude desktop app. Once added on one of those, it also appears in the Claude mobile app.

You'll need **the connector link** that Sadie sends you separately. Treat it like a password.

---

## If you have your own Claude plan (Free, Pro, Max)

1. Open **claude.ai** (or the desktop app) → **Customize** → **Connectors**.
2. Click **Add custom connector**.
3. Name: `Little Lantern Media Plans`. URL: paste the connector link.
4. If it asks about sign-in, choose **No sign-in**.
5. Click **Add**.

(On the Free plan you can have one custom connector.)

## If your organisation uses Claude Team or Enterprise

Only an organisation **Owner** can add a custom connector. If that's not you, forward these steps to your Owner:

1. **Organization settings** → **Connectors** → **Add** → **Custom** (choose **Web** if asked).
2. URL: paste the connector link. Leave the OAuth fields empty. Click **Add**.
3. Then each person goes to **Customize** → **Connectors**, finds **Little Lantern Media Plans** (labelled "Custom") and clicks **Connect**.

---

## Try it (about 10 minutes)

Start a **new chat**. Check the connector is switched on: **+** → **Connectors** → Little Lantern Media Plans.

You're a planner at Little Lantern Media. Type these one at a time:

1. *Start a new media plan for Bramble Bots.*
   Claude asks permission to show the plan: click **Allow**. The plan appears as a card, built from the client's brief.
2. *What reach do we have for 4–6 year olds?*
   Watch for the answer. The data only has 4–9, and the connector won't invent a 4–6 figure.
3. *Use the 4–9 figures where 4–6 isn't available, and remember that for next time.*
   This saves the decision in the agency's own rules file. Future plans use it automatically, still labelled as 4–9.
4. *Build a first draft: kids' TV, made-for-kids YouTube and parents' social, about half on TV. Run them all campaign.*
5. *Move 10% of the total budget from TV to YouTube.*
6. *Compare that with a TV-heavy option.*
7. Click **Open full plan**. Hover or tap any ⓘ to see exactly which file, sheet and cell each number came from.
8. *Give me the web link.* It's the same plan as a page anyone can open, print or save as PDF.

## What to notice

- **Every number comes from a file or a calculation.** Claude chooses and writes words; it never types a figure into the plan. Hover any number to check.
- **It won't make data up.** Age bands are never split or stretched to fit.
- **The plan always looks the same:** the agency's fixed 8-slide format.
- **Checks run after every change.** Budget totals, campaign dates, the agency's own rules, under-13s targeting, unconfirmed rates. Nothing says "pass" unless it was actually checked.
- **It goes back to the files every time.** If someone changes a number in a source spreadsheet, the plan flags it instead of using an old copy.
- **Decisions are remembered in the agency's folder,** not in Claude's memory.

## Can I use my own files?

In a real setup, yes. The connector reads and saves into your own OneDrive or SharePoint folder after you sign in with Microsoft, and nothing is kept on Signifii's side. For this demo, please stick to the fictional files.
